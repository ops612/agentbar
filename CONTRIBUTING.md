# Contributing

AgentBar doesn't take pull requests. The code is written by an agent, so contributions come in as **prompts**, not patches. PRs are closed automatically.

Want a feature or a fix? [Open a Prompt issue](../../issues/new?template=prompt.yml) and write what you'd tell the agent:

- Describe the **behavior** you want, not the implementation.
- Be specific. "Dim the icon when everything's been idle 30+ minutes" beats "improve the icon."
- Add context if it helps — your setup, what you tried, screenshots.

Good prompts get run against the codebase and shipped. Bug reports are welcome as regular issues.
